## 0. 设计决策（按你的确认定稿）

| # | 决策 |
|---|---|
| 1 | **一级 Tab 直达**：`手势` / `设置`（底部导航），不再"点进去再点进去" |
| 2 | **三指 / 四指 / 五指不再分 Tab**，而是**同一页里依次排列三张卡片**（对齐 Windows 图 1） |

| 6 | 横屏旋转档位**只作用于横屏**，竖屏恒按 0° 处理 |
| 7 | 零新依赖：图示用 `Canvas` 自绘，导航用 `when` + `BackHandler` |

## 2. 结构

```
┌── 顶部常驻状态条（运行中 / 未运行 / 未授权 Root）──┐
│  ● 手势服务运行中                          [管理]   │
└─────────────────────────────────────────────────────┘

[ ✋ 手势 ]            [ ⚙️ 设置 ]        ← 一级 Tab

手势页（同一页，滚动）
  ├ 三指手势卡：触点图示 + ↑↓←→ + 点击
  ├ 四指手势卡
  ├ 五指手势卡
  └ [ 高级手势 › ]

高级手势页（折叠分组）
  ├ ▾ 配置三指手势：点击 / 向上 / 向下 / 向左 / 向右
  ├ ▸ 配置四指手势
  └ ▸ 配置五指手势

设置页（单页）
  ├ 服务：Root / 服务 / 守护进程状态 + 启动 / 停止 / 重启守护
  ├ 外观：动态取色（Material You）
  ├ 方向校正：横屏旋转档位、横屏左右反向、实时「系统旋转 · 生效档位」
  ├ 手势映射：恢复默认映射
  ├ 行为：开机自启
  ├ 诊断与日志：默认折叠，展开才轮询（可暂停 / 清空）
  └ 关于：版本 / native core / GitHub 地址 / 许可
```

## 3. 交互要点

| 场景 | 行为 |
|---|---|
| 改映射 | 点卡片里任意一行 → 底部弹层选动作（≤ 2 次点击） |
| 选动作 | 弹层按「系统 / 媒体 / 其他」分组，支持搜索，当前项打勾 |
| 自定义命令 | 选「自定义快捷方式」→ 弹层内编辑 → **显式保存**才落盘（不再边打字边写文件） |
| 触点图示 | 手指停在/刚改过某方向时，该方向箭头高亮为主题色 |
| 返回 | 高级手势页按返回键 → 回手势页（一级页按返回退出） |
| 错误提示 | 顶部状态条 + `Snackbar`（不再是永久挂着的错误卡） |
| 日志 | 只在「设置 → 诊断与日志」展开时每 2 秒刷新 |

## 4. 横屏方向（定案实现）

```cpp
int rot = rotation_ & 3;                     // 系统旋转
if (rot == 1 || rot == 3) {                  // 仅横屏
    if (override_ in 0..3) rot = override_;  // 横屏档位（用户可强制，实测本机需要 90°）
    if (mirror_) rot = (rot == 1) ? 3 : 1;   // 横屏左右反向
}
// 竖屏（0 / 180）不做任何补偿
```

配置文件的第二个/第三个字段语义调整为：
`<系统旋转> <横屏左右反向 0|1> <横屏档位 -1|0..3>`（格式未变，向后兼容，旧键会自动读作档位）。
